# メニュー解説ドキュメントのフォーマット定義

Googleドキュメントを「種目解説マスター」として使うための記述ルール。
**プログラムから読み取りやすく、かつDocs上で人間が普通に読み書きできる**ことを両立させるため、
JSONではなく **見出し構造 + ラベル行** を採用する。

> JSONを本文に貼る方式は、Docsのスマート引用符（`"` → `“`）や自動改行で
> 簡単に `JSON.parse` が壊れるため採用していない。

---

## 構造

```
[タイトル]   筋トレ メニュー解説マスター     ← 任意。無視される
[見出し 1]   胸                            ← 部位（Menus シートの part と一致させる）
[見出し 2]   ベンチプレス                   ← 種目名（Menus シートの menu と一致させる）
[本文]       別名: ベンプレ, BP
[本文]       器具: バーベル
[本文]       主働筋: 大胸筋 / 三角筋前部 / 上腕三頭筋
[本文]       推奨レップ: 8〜12
[本文]       解説: 肩甲骨を寄せて下制し、みぞおち〜乳頭下のラインにバーを下ろす。
[本文]       胸郭を張ったまま、肘を軽く畳んだ軌道で押し切る。      ← ラベル無し行は直前ラベルの続き
[本文]       ポイント: 足で床を押し、下半身の力を体幹経由でバーに伝える
[本文]       ポイント: 手首を寝かせず、前腕をバーの真下に垂直に保つ
[本文]       注意: 肩がすくむと大胸筋から負荷が抜け、肩を痛めやすい
[本文]       YouTube: 山岸秀匡のベンチプレス解説 | https://www.youtube.com/watch?v=XXXXXXXXXXX
[本文]       タグ: コンパウンド, 高重量

[見出し 2]   インクラインダンベルプレス      ← 同じ部位の次の種目
...
[見出し 1]   背中                          ← 次の部位
```

段落スタイルは Docsのツールバー左の「標準テキスト ▾」から
**「見出し 1」「見出し 2」** を選んで設定する（文字を大きくしただけでは認識されない）。

## ラベル一覧

| ラベル | 別表記 | 複数行 | 出力先 | 内容 |
|---|---|:---:|---|---|
| `解説:` | `説明:` | 連結 | `description` | 種目の解説本文。複数行書くと改行付きで連結される |
| `ポイント:` | `コツ:` | ✓ | `points[]` | 意識すべき点。行を分けるか `,` `、` `/` 区切りで複数指定 |
| `注意:` | `NG:` | ✓ | `cautions[]` | よくある失敗・怪我のリスク |
| `YouTube:` | `動画:` | ✓ | `videos[]` | `タイトル \| URL` または URL のみ |
| `タグ:` | — | ✓ | `tags[]` | 分類ラベル |
| `別名:` | — | ✓ | `aliases[]` | 表記ゆれ吸収用。Menusシートの種目名と綴りが違うときに使う |
| `器具:` | — | — | `equipment` | バーベル / ダンベル / マシン / ケーブル / 自重 |
| `主働筋:` | `対象筋:` | ✓ | `muscles[]` | 主に効かせる筋肉 |
| `推奨レップ:` | `レップ:` | — | `repRange` | 表示用の文字列（例 `8〜12`） |

### 記述の細則

- コロンは **半角 `:` / 全角 `：` どちらでも可**。ラベル名の前後の空白は無視される。
- ラベルが付いていない本文行は、**直前のラベルの続き**として扱われる（`解説:` を長文にする場合に便利）。
  種目の先頭でラベル無し行が来た場合は `解説` 扱いになる。
- 複数値の区切りは `,` `、` `/` `|` `｜`。
- `YouTube:` はURLを直接書いても、Docsのリンク機能でテキストにリンクを貼っても、どちらでも読み取れる。
  タイトルを付けたい場合は `タイトル | URL` の形式にする。
- **箇条書き（リスト）にしても読み取れる**が、ラベルは各行の先頭に必要。

## 種目名の照合ルール

アプリは「スプレッドシートの Menus」と「ドキュメントの解説」を種目名で突き合わせる。
照合は以下の順で行われ、いずれもヒットしなければ「解説なし」と表示される。

1. 部位・種目名の両方が一致（空白・全半角カッコを除去し、小文字化して比較）
2. 種目名のみ一致
3. `別名:` に一致

そのため、**Menus シートの `menu` 列と、ドキュメントの見出し2は同じ文言にしておくのが確実**。
どうしても揃わない場合は `別名:` に Menus 側の表記を書いておく。

## 初期データについて

`seedGuideDoc()` を実行すると、Notion「筋トre」ページから取り込んだ46種目の見出しと、
本文のあった15種目の解説・YouTubeリンクがこのフォーマットで書き込まれる
（取り込み結果の原文は [notion-guide-source.md](notion-guide-source.md)）。
本文が無かった31種目は見出しだけが入るので、Googleドキュメント上で `解説:` を書き足していけばよい。

## キャッシュ

ドキュメントのパース結果は GAS 側で **10分間キャッシュ** される（`DocRepo.gs` の `GUIDE_CACHE_SEC`）。
編集を即座に反映したいときは、アプリの **設定 → 「解説ドキュメントを再読込」** を押す。

## 執筆時の指針（山岸秀匡選手の理論ベースで書く場合）

解説を書き足すときは、以下の観点を1種目ずつ埋めていくと粒度が揃う。

- **解説**：スタートポジション → 動作軌道 → フィニッシュの順に、体の使い方を1〜3文で
- **ポイント**：ターゲット筋に効かせるための意識（可動域、ストレッチ、収縮、テンポ）
- **注意**：負荷が逃げる代償動作、怪我につながるフォーム
- **YouTube**：フォーム解説の該当動画。複数行書けば複数リンクを表示できる

> 引用元の動画・文章をそのまま転載せず、リンクと要点の記述にとどめてください。
