# LiftLog デザイン案 01 ／ ダーク × ネオン

本体のアプリには一切触れていません。この `prototype/` だけで完結します。
公開先: https://aenocyon13.github.io/liftlog/prototype/

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ロゴ（SVG）、配色・書体の見本、端末4台分のマークアップ |
| `proto.css` | この案だけのトークンと部品。本体の `css/style.css` とは独立 |
| `scenes.js` | 3Dシーン4つ（ホーム背景・部位選択の人体・完了演出・レポートの棒） |
| `proto.js` | 画面の中の小さな動き（タイマー、部位の選択、ステッパー） |

## 決めたこと

- **下地はほぼ黒**（`#06070A`）。ジムは暗いので、画面を明るくしない。
- **ネオンは役割で使い分ける**。ライム＝いま・達成、シアン＝過去・情報、
  マゼンタ＝自己ベスト、アンバー＝休憩。色を見れば意味が分かる状態を保つ。
- **画像ファイルは使わない**。ロゴもアイコンも背景もコードで描く。
  拡大しても崩れず、合計でも数十KBで済む。
- **3Dは用途で強さを変える**。背景は飾り、人体は道具、完了演出は3秒で消す。
- 画面に映っていないシーンは `IntersectionObserver` で描画を止める。

## 本体へ移すとき

`proto.css` の `:root` と部品のクラスを本体の `css/style.css` に写し、
`scenes.js` はそのまま `js/` に置けます。Three.js は importmap から CDN 経由で
読んでいるので、ビルド作業は増えません。
